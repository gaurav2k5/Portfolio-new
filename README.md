# Gaurav Pratap Singh — Portfolio & Visual Studio

A cinematic, brutalist-editorial design portfolio and interactive visual exhibition for **Gaurav Pratap Singh**, Graphic Designer & Visual Creative.

Built with **Next.js 14 (App Router)**, **React Three Fiber / Three.js**, **Tailwind CSS**, and **Framer Motion**.

---

## ✨ Features

- **3D Interactive Virtual Studio**: Interactive 3D gallery built with React Three Fiber, featuring physical-light poster displays, dynamic spotlight controls, smooth camera navigation, and ambient dust particles.
- **Cinematic Curated Showcase**: High-impact editorial layout showcasing brand identities, luxury packaging, high-contrast poster art, and typography experiments.
- **Deep Case Study Breakdowns**: Full-screen modal inspection detailing creative concept, typographic hierarchy, color systems, and delivery artifacts.
- **Editorial Typography**: Pairing of **Cormorant Garamond**, **Manrope**, and **IBM Plex Mono** with bespoke gold-leaf accents, brutalist grid lines, and smooth micro-interactions.
- **Responsive & Accessible**: Fully responsive across mobile, tablet, and ultra-wide displays with keyboard navigation and fluid layouts.

## 🚀 Getting Started

### Prerequisites

- Node.js 18.17 or higher
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/<repo-name>.git
   cd <repo-name>
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Production Build

To build the static optimized application:

```bash
npm run build
npm run start
```
